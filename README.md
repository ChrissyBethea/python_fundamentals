# Python Fundamentals

This repository contains Python practice programs for INFO U762 Interoperability.

## Simple Interest Calculator

The `simple_interest_calculator.py` program calculates simple interest using the principal amount, interest rate, and time in years entered by the user.

The program includes input validation, exception handling, string manipulation, and formatted output.

### How to Run

1. Open `simple_interest_calculator.py` in Visual Studio Code.
2. Run the program using Python 3.
3. Enter your name, principal amount, interest rate, and time in years when prompted.
4. The program will display the calculated simple interest and total amount.

### Testing

I tested the program using both valid and invalid input. For an edge case, I entered `abc` when the program requested the principal amount. The program displayed an error message and allowed me to enter a valid number instead of terminating.

I also tested the program using a principal of $1000, an interest rate of 5%, and a time of 2 years. The program correctly calculated $100.00 in simple interest and a total amount of $1100.00.
